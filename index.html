インストール

Install

1

DMG をダウンロード

Download the DMG

GitHub Releases から最新版を取得。

Get the latest build from GitHub Releases.

2

Applications にドラッグ

Drag to Applications

DMG を開き、K-Tech PowerGuard を Applications フォルダへ。

Open the DMG and drag K-Tech PowerGuard to Applications.

3

エラーが出ても削除しない

If an error appears, do not delete

クリック時に「開けない」と出ることがあります。削除は選ばないでください。 システム設定 → プライバシーとセキュリティ を下へスクロールし、K-Tech PowerGuard の このまま開く を押します。確認が出たらもう一度押すと利用できます。

Clicking the app may show that it cannot be opened. Do not choose Delete (or Move to Trash). Open System Settings → Privacy & Security, scroll down, and press Open Anyway for K-Tech PowerGuard. If asked again, press it once more.

4

通知を許可

Allow notifications

システム設定 → 通知 で K-Tech PowerGuard を許可。メニューバーから設定できます。

Allow K-Tech PowerGuard in System Settings → Notifications. Then open Settings from the menu bar.

⚠️ 初回クリックでエラーが出ても 削除は選ばないでください。 システム設定 → プライバシーとセキュリティ に K-Tech PowerGuard と このまま開く が出ます。充電の物理停止は macOS では行いません—通知のみです。
⚠️ If the first click shows an error, do not choose Delete (or Move to Trash). In System Settings → Privacy & Security, K-Tech PowerGuard appears with Open Anyway. The app notifies only—it does not stop charging hardware.
