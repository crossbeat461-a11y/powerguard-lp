インストール

Install

1

DMG をダウンロード

Download the DMG

GitHub Releases から最新版を取得。

Get the latest build from GitHub Releases.

2

Applications にドラッグ

Drag to Applications

DMG を開き、K-Tech PowerGuard を Applications フォルダへ。

Open the DMG and drag K-Tech PowerGuard to Applications.

3

初回起動 & 通知許可

First launch & notifications

右クリック →「開く」。システム設定 → 通知で PowerGuard を許可。

Right-click → Open. Allow notifications in System Settings.

⚠️ 初回起動時は Gatekeeper のため 右クリック →「開く」 が必要な場合があります。充電の物理停止は macOS では行いません—通知のみです。
⚠️ On first launch you may need right-click → Open for Gatekeeper. The app notifies only—it does not stop charging hardware.
